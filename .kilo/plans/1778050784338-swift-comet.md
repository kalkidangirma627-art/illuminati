# Fix Login "Invalid Credentials" + Registration "Server Unreachable"

## Root Cause Analysis

### Issue 1: Registration "Server Unreachable" on Vercel frontend
- The Vercel frontend (`https://illuminati-pi.vercel.app`) is serving **stale/cached** files
- Vercel may not have auto-redeployed after the latest commits
- The `register.html` on Vercel still points to the old API URL or has cached JS

### Issue 2: Login "Invalid Credentials" for MongoDB users
Two possible causes identified:

**A. Missing try/catch in login handler** (`server.js:112-122`)
- `User.findOne({ email })` has NO try/catch wrapper
- If Mongoose connection drops or times out, the promise rejects unhandled
- This causes the server to crash/return 500 instead of proper error
- Client sees this as a network error or gets a non-JSON response

**B. `useFallback` state may be stale** 
- `setupDb()` at line 99 is async but called WITHOUT `await`
- If MongoDB connection takes time, routes can execute before DB is ready
- LoginHandler checks `useFallback` (line 114) but `useFallback` might not reflect actual connection state

**C. Mongoose `_id` type mismatch**
- Mongoose `findById` uses ObjectId, but `User.findOne({ email })` should work fine for email lookup
- Less likely but possible if the collection has mixed _id types

## Fix Plan

### Fix 1: Add try/catch to login handler (server.js:112-122)
- Wrap the entire login logic in try/catch
- Return proper JSON errors instead of crashing
- Add explicit connection state check before querying

### Fix 2: Add defensive try/catch to ALL route handlers that query MongoDB
- Register, user/me, agent/members, member/requirements, etc.
- Every handler that does `await User.find()`, `await X.findOne()`, etc. needs try/catch
- Currently NONE of them have error handling for DB failures

### Fix 3: Ensure `useFallback` accurately reflects connection state
- Add a periodic check or event listener on mongoose connection
- Set `useFallback = true` if connection drops after initial connect
- This ensures the fallback system works if MongoDB becomes unavailable

### Fix 4: Force Vercel frontend redeploy
- Push an empty commit to trigger Vercel auto-deploy
- This ensures the latest `register.html` and `login.html` are served
