## PART 2: Prepare the Code for Railway

### Step 2.1: Add a `start` script to package.json
Railway needs a `start` script to know how to run the app.
- Open `package.json`
- In the `scripts` section, add: `"start": "node server.js"`
- The section should look like:
  ```json
  "scripts": {
    "dev": "vite",
    "build": "vite build",
    "lint": "eslint .",
    "preview": "vite preview",
    "start:all": "concurrently \"npm run dev\" \"node server.js\"",
    "start": "node server.js"
  }
  ```

### Step 2.2: Ensure server.js listens on all interfaces
Railway requires the app to bind to `0.0.0.0` (not just localhost).
- Open `server.js` line 205
- Current: `app.listen(PORT, () => console.log(...))`
- Change to: `app.listen(PORT, '0.0.0.0', () => console.log(...))`

### Step 2.3: Verify PORT handling
- `server.js` line 16 already uses `process.env.PORT || 3001` — good
- Railway injects `PORT` env var automatically, so the app will use Railway's port

## Troubleshooting

### Issue: Railway deploy fails — "npm start" crashes
1. Check Railway logs for the error
2. Most likely cause: MongoDB Atlas connection failure
3. Fix: Ensure `0.0.0.0/0` is in MongoDB Atlas Network Access

### Issue: MongoDB Atlas connection fails from Railway
1. Go to MongoDB Atlas → Network Access → IP Access List
2. Confirm `0.0.0.0/0` is present
3. If not, add it and wait 2 minutes
4. Redeploy on Railway

### Issue: CORS errors in browser console
1. Check the exact error message — it shows which origin is blocked
2. Add that origin to the CORS config in `server.js`
3. Push and wait for Railway to redeploy

### Issue: "502 Bad Gateway" on Railway
1. Check Railway logs
2. Verify the app is binding to `0.0.0.0` not `localhost`
3. Verify `PORT` env var is being used

### Issue: Railway free trial runs out
- Railway's free trial gives $5 credit
- A small Node.js app uses ~$3-5/month
- You'll need to add a payment method or switch to Render (which has a free tier)

### Issue: Git push asks for password and fails
- GitHub no longer accepts account passwords for git operations
- You must use a Personal Access Token (PAT)
- Generate one at https://github.com/settings/tokens/new with `repo` scope
- Use the token as your password
